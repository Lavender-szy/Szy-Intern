	——机构怎样把多个因子组合起来，并真正落地成可投资的指数配置
# 1.核心术语
1. 多因子指数：把若干单因子指数按预定权重合并成一个统一指数
2. 可投资性：指数是否容易交易、复制并容纳大规模资金
3. 跟踪误差/主动风险：指数相对母指数的收益差有多不稳定
4. 信息比率：平均主动收益相对于跟踪误差的效率
5. 自然交叉/内部对冲成交：一个子指数要卖、另一个子指数要买同一股票时，在组合内部抵消交易
# 2.多因子配置vs多因子指数
## 2.1 多因子配置
**投资者的决策**：
选哪些**因子**；每个**因子**占比；长期保持或动态调整
## 2.2 多因子指数
**将投资者的决策量化**：
具体持有哪些**股票**；每个**股票**权重多少；**多久**重新调整；指数每天怎样计算
# 3.为什么因子投资处在被动与主动之间
![[Pasted image 20260727165037.png]]
==收益来源：全球股票贝塔+附加价值==
左侧是广泛市场贝塔（市值加权基准）；中间是因子投资，由**多因子指数**承载长期战略倾斜，也可叠加战术因子调整；右侧是主动管理，包括战术资产配置、个股选择和市场择时。
**左侧：被动贝塔** Passive Investing
- 贝塔：机构通过广泛持有市场、也就是**完整股票投资机会集**所获得的收益，通常可通过被动跟踪市值加权指数实现。全球投资中，MSCI、ACWI、IMI等宽基指数=全球股票贝塔
	- 实际实现方法eg：买跟踪宽基指数的指数基金或ETF
- 被动贝塔：通过**被动复制**市场，获得**市场整体回报**（==资金100%都按照宽基指数==）
	- if主动调整市场暴露，即调整宽基指数的股票在自己所有资金里的占比，为主动贝塔
**中间：因子投资**
- **战略**因子倾斜 Strategic Factor Tilts：**长期**、相对**稳定**地配置某些因子，长期相对**静态**
- **战术**因子倾斜 Tactical Factor Tilts：根据未来判断，暂时调整比例，根据前瞻判断**动态**超配或低配
**右侧：主动阿尔法** Active Management
- 阿尔法：（定义见[[研报——因子投资的基础#因子的额外收益]]）超出基准、不能由基准解释的附加收益
- 主动阿尔法：通过**主动判断**，争取超越市场基准的**附加收益**
**市场指数负责“拥有市场”，因子指数负责“有规则地偏向某些特征”，主动管理负责“做规则难以完成的判断”。**

## 3.1多因子指数的四项潜在好处
### 1.灵活性
机构可以决定：
- 用哪些因子；
- 每个因子多少；
- 是否加入ESG限制；
- 是否长期保持；
- 是否用ETF做临时调整。
例如：
#### 防御型机构
可能偏向：
- 低波动；
- 质量；
- 高股息。
#### 进取型机构
可能偏向：
- 动量；
- 小市值；
- 价值。
### 2.透明度
多因子指数则可以明确看到：
- 每个单因子指数；
- 每个因子的目标权重；
- 底层股票；
- 当前风险和暴露。
### 3.成本效率：可能减少费用和重复交易
- 原因一：指数可以被动复制，可能比主动基金更便宜
- 原因二：若多个因子在统一组合内再平衡，还可能发生**自然交叉**，减少实际买卖
### 4.分散化
不同因子的冬天不完全重合

# 4.实施多因子指数配置的三个维度
![[{D4D783F2-6000-41F1-BA70-6E2C5FF74719}.png]]
## 4.1 计划目标与约束
- 计划目标：要解决什么问题
	- 降低整个组合的波动；
	- 在风险不变时提高收益；
	- 提高现金分红；
	- 替代部分收费较高的主动基金；
	- 减少某一种经济环境的影响。
- 约束：不能做或承受不了的
	- 投资期限；
	- 风险预算；
	- 资金规模；
	- 治理能力；
	- 流动性需要；
	- ESG规则；
	- 是否允许做空或使用杠杆。
## 4.2 因子组合
eg.
- 为降低风险，候选因子组合：**低波动**+**质量**+**高股息**因子
	- 从市场波动、企业质量、现金收入三个角度增加防御性
- 能承受较大波动，为提高长期收益，**小市值**+**动量**+**价值**因子
	- 更侧重收益潜力，而非只关注稳定性
## 4.3实施考量

### 4.3.1 因子暴露 vs 可投资性
==指数不是越“纯”越好==
![[Pasted image 20260807164837.png]]

从金字塔下到上：
- 市值加权母指数 → **可投资性最高，因子暴露最弱**
- 高容量因子指数 → 保留母指数大部分/全部股票，通过重新加权获得因子倾斜
- 高暴露因子指数 → 持股更集中，目标因子更“纯”
- 多空因子指数 / 市场中性因子指数 → 因子暴露更强，但实施更复杂
- 理论纯因子 → 主要用于研究，**不适合直接大规模投资**

向上移动的代价：
- 因子暴露↑
- 跟踪误差↑
- 集中度↑
- 容量↓
- 流动性/复制便利性↓
- 还可能产生**行业、国家、其他因子的意外暴露**

### 4.3.2 什么是因子暴露
- 因子暴露：指数在多大程度上捕捉理论上的纯因子
- 通常表示为：相对于市值加权市场平均水平偏离多少个**标准差**
- 在线性因子模型中：
	- 指数因子暴露 = 成分股因子暴露按指数权重加权后的总和
- 量化投资里也可以理解为**信号强度**
	eg. 价值因子暴露=0.25：组合的价值特征比市值加权基准高约0.25个标准差

![[Pasted image 20260807164935.png]]

- 一个指数除了目标因子，还可能带有**次级因子暴露**
- eg. 风险加权指数除了低波动倾斜，还明显偏向小市值
- 所以不能只看指数名字，要看真实暴露

### 4.3.3 什么是可投资性
可投资性不只是“能不能买”，还包括：
- **可交易性/流动性**：初始建仓和再平衡需要多少天完成
- **换手率/复制成本**：调整仓位的幅度，换手越高通常交易成本越高
- **容量**：资金规模变大后，是否会持有某只股票过高比例
- **主动倾斜程度**：相对母指数偏离多大，可用主动份额、最大策略权重等衡量

![[Pasted image 20260807165000.png]]

### 4.3.4 实施时真正要权衡什么
==因子浓度 vs 现实可复制性==
- 大资金、低主动风险预算 → 更适合**高容量、低跟踪误差**方案
- 能接受更高主动风险、较强治理能力 → 可考虑**更高暴露**方案
- 高暴露不自动等于高收益：如果同时产生无意的行业/国家/其他因子押注，可能抵消目标因子的收益

![[Pasted image 20260807165026.png]]

- 价值加权：持有母指数全部股票，**主动风险较低、换手较低**，属于高容量思路
- 动量：因子暴露明确，但**换手率非常高**
- 质量、最小波动、动量通常只持有部分股票，集中度更高，可投资性相对更低


# 5.因子的选择
## 5.1 根据自己的目标选择因子
- 首先排除自己认为未来不能持续的因子
- 选择因子的起点：
	- 投资目标；
	- 投资期限；
	- 风险承受能力；
	- 治理能力；
	- 资金规模
## 5.2 不同因子的收益和风险
![[Pasted image 20260729162848.png]]
横轴：年化风险；纵轴：年化收益
	将因子按照市场表现分为四类，以MSCI World为对比基准
- **左上**：低风险高收益
	- 质量因子：体现出较好的风险收益组合
- **右上**：高风险高收益
	- 动量因子：历史收益潜力较高，但不靠低波动获得
- **左下**：低风险低收益
	- 低波动因子：历史结果中，确实实现了较低的绝对波动
- **右下**：高风险低收益
	- 等权重（小市值因子）：风险和收益都高于基准
	- 价值加权指数：风险接近市场，收益略高于市场，在承受与市场相似风险的情况下，历史上获得了一定额外收益

## 5.3顺周期&防御型
### 5.3.1 顺周期
经济增长、通货膨胀和利率上升时，历史表现往往较好——**价值、动量和小市值因子**
	经济状态好，投资者愿意承担风险时更容易受益
### 5.3.2 防御型
经济环境减弱或较差时，历史表现往往较好——**质量和低波动因子**
	在较差环境中更有韧性
==并非绝对规律==

# 4.多因子组合改变了什么
![[{79DCF339-1DB1-4550-AE0A-8B90FF11000C}.png]]
组合了
- 质量指数；
- 风险加权指数；
- 价值加权指数；
- 动量指数。
**把组合结果与MSCI World以及各单因子进行比较：**
	主动收益、跟踪误差、信息比率、相对回撤
- 跟踪误差：主动收益序列的年化标准差
	- 组合的跟踪误差比单因子的跟踪误差都低——比每个单因子都更加稳定
- ==低相关性发挥的作用==
- 信息比率
- 主动收益：比基准多赚了多少
**不考虑基准，单独观察组合：**
	总收益、总风险、夏普比率
- 组合风险≠各因子的平均值，取决于之间的相关性
- 收益/风险比=年化总收益/年化总风险
	- 问题：没有扣除无风险收益
- **夏普比率**：
$$
\text{夏普比率} = \frac{\text{组合收益} - \text{无风险利率}}{\text{组合总风险}}
$$
	夏普比率没有百分号
	指数超过无风险利率的收益，是否足以补偿承担的总风险。
	（因子组合承担了股票波动后，比相对安全的投资多赚了多少？）

# 自然交叉为什么能降低交易成本
==多因子组合不仅改变收益和风险，还会改变真实交易路径==

自然交叉/内部对冲成交：
- 同一个再平衡日，某只股票可能被一个因子指数**卖出**，同时被另一个因子指数**买入**
- eg. 一只股票持续下跌：
	- 动量变弱 → 动量指数想卖
	- 估值变便宜 → 价值指数想买
- 如果两个因子统一管理，这部分交易可以在组合内部直接抵消，不需要先去市场卖、再重新买回来

成立条件：
- 底层因子指数要**同步再平衡**
- 多因子权重调整也要在同一时间进行
- 如果多个授权彼此独立、再平衡日期不同 → 自然交叉机会会明显减少

![[Pasted image 20260807165200.png]]
四因子等权组合（质量、风险加权、价值加权、动量）的历史例子：
- 分开管理换手率：40.81%
- 统一管理换手率：31.91%
- ==减少8.90个百分点==
- 假设单只证券交易成本50bp：成本拖累约从41bp降至32bp，节约接近9bp

**关键：** 多因子组合的成本优势不只是“指数基金管理费低”，还可能来自**组合内部少交易**。

# 怎么评价一个多因子组合
![[Pasted image 20260807165256.png]]
不能只看收益，要同时看四类指标：

## 1.绩效
- 总收益、总风险、夏普比率
- 主动收益、跟踪误差、信息比率
- VaR、预期损失
- 最大回撤及持续期
- 相对最大回撤
- 连续跑输年数

## 2.暴露
- 主动因子暴露
- 行业/地区暴露
- 相对估值和基本面比率

## 3.可投资性
- 流动性
- 复制成本/换手
- 容量
- 集中度

## 4.组合效果
- **收益分散化**：不同因子的弱势期是否互相错开
- **换手降低**：统一管理后是否通过自然交叉减少交易

==评价多因子组合，本质上是看它是否更符合机构目标，而不是看哪项单一指标最高。==

# 多因子配置的三种实施方式
1. **长期战略分散配置**
	- 价值、动量、风险加权、质量
	- 统一指数实施
	- 半年再平衡
	- 适合长期获取风险调整后收益
2. **降风险并提高收益率/现金收益**
	- 最小波动 + 高股息
	- 用于希望降低整体波动、同时提高股息收入的机构
3. **核心 + 战术叠加**
	- 核心：最小波动 + 高股息
	- 战术：根据前瞻判断，用ETF动态调整动量、质量、价值、等权重等暴露

# 案例1：长期战略性风险调整后收益配置
组合权重：
- 价值加权 25%
- 风险加权 25%
- 质量 25%
- 动量 25%
![[Pasted image 20260807165320.png]]

- 不同因子在不同时期轮流强弱
- 风险加权在整个历史样本中累计领先最多
- 但合并组合不是追求“最高那条线”，而是让曲线更平滑

![[Pasted image 20260807165337.png]]
- 合并组合总收益：6.7%
- 总风险：14.9%（低于MSCI World的16.3%）
- 主动收益：2.5%
- 跟踪误差：3.0%（低于四个单因子）
- 信息比率：0.83（高于四个单因子）
- 换手率：32.0%，远低于动量的89.6%

==重点不是合并组合收益最高，而是它牺牲部分单因子的极端高收益，换来更稳定的主动收益和更低的相对风险。==

# 案例2：降低风险 + 提高股息收益率
组合权重：
- 最小波动 50%
- 高股息 50%

目标：
- 降低整体波动
- 同时提高现金股息收入
![[Pasted image 20260807165359.png]]

- 两个单因子在部分时期明显分化
- 合并组合大多位于两者之间 → 体现分散效果
![[Pasted image 20260807165428.png]]

关键结果：
- 合并组合总收益：6.3%
- 总风险：13.5%
	- 高于最小波动11.4%
	- 低于高股息16.1%
- 信息比率：0.33，高于两个单因子
- 平均股息率：3.3%
	- 高于MSCI World 2.3%
	- 低于高股息4.0%

==这个组合没有同时拿到“最低风险”和“最高股息”，而是在两个目标之间做折中。==


因子配置的顺序：
1. 先问：**因子投资在我的整体组合里要解决什么问题？**
2. 再选：**哪些因子符合我的信念、目标和约束？**
3. 最后决定：**用什么指数和实施结构把因子配置落地？**

实施时同时考虑：
- 因子之间的相关性和周期分散
- 因子暴露强度
- 跟踪误差/主动风险
- 流动性和容量
- 换手和交易成本
- 治理能力与投资期限

==不要从“哪只指数历史收益最高”出发，而要从“我的目标、约束和因子信念是什么”出发；再在因子组合、分散化、暴露纯度、跟踪误差、容量和成本之间做一致设计。==
