## 数据口径

* 数据: `data/raw/stock/MktEqudAdjAfGet/*.csv`, 每只股票一个后复权日线 csv。
* 样本: 剔除 78 只 B 股后 5,206 只 A 股, 2015-01-05 ~ 2026-08-12, 2,821 个交易日。
* 窗口: 5 / 20 / 60 / 120 / 252 个交易日; 60 及以上窗口的动量跳过最近 20 天。
* 检验: t 日因子预测 t+1 日收益; 月度回测每月最后交易日调仓、等权持有下月。

## 如何运行

脚本都支持从 `scripts/` 子目录直接运行(会自动定位项目根目录), 也可放回根目录运行:

```bash
# 按依赖顺序执行
python scripts/01_数据准备_因子构建/构建因子库.py       # 1) 建因子库
python scripts/01_数据准备_因子构建/提取市值面板.py      # 2) 市值面板
python scripts/02_数据清洗/阶段0_数据清洗.py             # 3) 清洗标记
python scripts/03_单因子检验/单因子检验.py               # 4) 单因子检验
python scripts/04_相关性_中性化/第二阶段A_相关性_中性化.py  # 5) 相关性+中性化
python scripts/05_回测_合成/第二阶段B_月度回测_合成.py      # 6) 回测+合成
python scripts/03_单因子检验/阶段0_清洗后检验.py          # 7) 清洗后检验
python scripts/05_回测_合成/阶段0_清洗后回测.py           # 8) 清洗后回测+合成
```

说明:
* 单因子检验支持 `--family xxx` 只跑某个因子族, 中断后重跑自动跳过已完成因子;
* 因子默认存 gzip pickle, 装了 pyarrow 会自动改存 parquet;
* `panel.pkl.gz` 是建库缓存, 删除后重跑会自动重新读 csv。
